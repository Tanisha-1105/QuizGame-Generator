# QuizGame Generator 🎯

QuizGame Generator is a Java Swing desktop application designed to help students practice technical multiple-choice questions (MCQs) across various computer science subjects. Users can select a subject, choose a difficulty level, and customize the number of questions for each quiz.

## ✨ Features

- **16 Technical Subjects** covering programming, databases, networking, and more.
- **Built-in Question Bank** containing 512 question entries.
- **Difficulty Selection** — Easy, Medium, Hard, or Any Difficulty.
- **Custom Quiz Length** — Select the number of questions for your quiz.
- **Randomized Questions** to provide varied quiz sessions.
- **Multiple-Choice Questions** with four answer options.
- **Answer Validation** with explanations.
- **Score Calculation** with final score and percentage.
- **Light Theme UI** for a clean and readable experience.
- **Offline Support** to practice without an internet connection.

## ⚙️ Prerequisites

Before running the application, install:

- Java Development Kit (JDK) 17 or later
- Apache Maven
- Visual Studio Code or another Java-compatible IDE

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Tanisha-1105/QuizGame-Generator.git
cd QuizGame-Generator
```

### 2. Compile the application

```bash
mvn clean compile
```

### 3. Run the application

```bash
mvn exec:java
```

The QuizGame Generator window will open.

## 🎮 How to Use

1. Launch the application.
2. Select a technical subject.
3. Choose a difficulty level.
4. Select the number of questions.
5. Click **Start Quiz**.
6. Answer the displayed MCQs.
7. Review the correct answers and explanations.
8. View your final score and percentage.
